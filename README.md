# A SIMPLE CALCULATOR PROJECT IN C

I hit a bottleneck while trying to understand how compilers operator, I had to look through tons of documentation and finally decided to
start from the basic by building and parsing a simple calculator.
This simple calculator can perform addition, subtraction, multiplication, and division of two numbers provided as input. 

Frankly speaking I don't have high hope for this project apart from the fact that it is learning project that can get me to know more
about my craft and interest in low level programming.
